# 💰 Expense Tracker App (Data Science Project)

## 📌 Overview
This is a beginner-friendly Expense Tracker App built using Python and Streamlit. It helps users track expenses, visualize spending patterns, and monitor budget usage.

The project uses synthetic data and demonstrates real-world data analysis and financial tracking concepts.

---

## 🎯 Features
- Add daily expenses
- View all transactions in a table
- Delete expenses
- Category-wise spending analysis
- Monthly spending trends
- Budget limit warning (overspending alerts)
- Interactive Streamlit dashboard

---

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

---

## 📊 Project Workflow
User Input → Data Storage (CSV) → Processing → Analysis → Visualization → Insights
